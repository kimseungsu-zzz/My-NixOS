# Upstream source

The `bar/` and `leftbar/` directories are based on the complete configurations from:
https://github.com/saimoomedits/eww-widgets

Imported from upstream revision `cfb2523a4e37ed2979e964998d9a4c37232b2975`.

Local changes are limited to KDE/NixOS compatibility: explicit monitor targeting, Eww's reserved `systray` widget name, scripts and dependencies available on NixOS, and replacing BSPWM workspace/session commands with KDE equivalents. Upstream did not include a LICENSE file at the imported revision.
